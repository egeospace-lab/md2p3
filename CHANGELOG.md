## [1.0.0](https://github.com/egeospace-lab/md2p3) - 2026-10-18

### Initial Release

The first stable release of **md2p3**, an open-source Python tool to convert Markdown files into PowerPoint presentations.

### Features
- Core CLI tool (`md2p3.py`) to generate PPTX files from Markdown.
- Support for configurable **Slide Maps** and custom templates.
- Implemented core slide classes:
  - Cover Slide
  - Notice Slide
  - Agenda Slide
  - Theme Slide
  - Content Slide
  - Final Slide
- Markdown formatting support for **bold**, *italic*, and inline code.
- Companion tool (`view-layout.py`) to inspect PPTX templates and export layout/placeholder metadata.

### Documentation
- Added initial README with installation and usage instructions.
- CONTRIBUTING and SECURITY guidelines drafted for community collaboration.
