# Security Policy – MD2P3 Project

We take the security of **md2p3** seriously.
This document outlines how to report vulnerabilities and our commitment to addressing them responsibly.

## Supported Versions

We provide security updates for the following versions:

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

Please ensure you are running the latest release of **md2p3** to benefit from security patches and improvements.

## Reporting a Vulnerability

If you discover a security vulnerability in **md2p3**, please report it responsibly:

1. **Do not disclose publicly** until we have investigated and released a fix.
2. **Email us directly** at: [md2p3@egeospace.in](mailto:md2p3@egeospace.in)
  - Include a detailed description of the issue.
  - Provide steps to reproduce the vulnerability.
  - Share proof‑of‑concept code or screenshots if available.
3. We generally acknowledge receipt within **72 hours** and provide a timeline for investigation and remediation.

## Our Commitment

- Investigate all reported vulnerabilities promptly.
- Communicate transparently with the reporter throughout the process.
- Publish a security advisory once the issue is resolved.
- Credit the reporter if they wish to be acknowledged.

## Responsible Disclosure

We encourage responsible disclosure practices:
- Avoid exploiting vulnerabilities in production environments.
- Do not attempt to access or modify data without authorisation.
- Work with us privately until a fix is released.

## Contact

For all security‑related inquiries, please contact: [md2p3@egeospace.in](mailto:md2p3@egeospace.in)

Thank you for helping keep **md2p3** secure and reliable for the community.
